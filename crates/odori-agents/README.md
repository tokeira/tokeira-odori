# odori-agents

`odori-agents` defines Odori's `Agent`, `Runner`, `Tool`, `Handoff`, and
`Guardrail` primitives, plus typed outputs and the durable run-loop workflow.
Provider turns are activities, handoffs are child workflows, and budget
decisions are derived from recorded history.

See the [primitives guide](https://github.com/tokeira/tokeira-odori/blob/main/docs/primitives.md)
and [budgets and handoffs guide](https://github.com/tokeira/tokeira-odori/blob/main/docs/budgets-and-handoffs.md).
