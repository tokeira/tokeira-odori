# odori-providers

`odori-providers` supplies Odori's subscription-first Claude Code and Codex
providers. It also provides raw Anthropic and OpenAI API backends behind
opt-in features.

The subscription providers supervise the vendors' authenticated CLI harnesses,
which remain runtime dependencies. Follow the [provider setup and error guide](https://github.com/tokeira/tokeira-odori/blob/main/docs/providers.md)
before running a live turn.
